# 我的 4399 小游戏合集

用豆包大模型（Doubao-Seed-Evolving）+ Trae 搓出来的摸鱼小游戏合集，包含一个 4399 风格的游戏平台和两款小游戏。

## 包含的游戏

| 游戏 | 类型 | 说明 |
| --- | --- | --- |
| **Flappy Bird** | 敏捷 / 双人 | 经典像素小鸟，支持双人同屏对战（空格 / W 键） |
| **城市狂飙 3D** | 赛车 / 3D | Three.js 打造的 3D 赛车躲避游戏，可输入城市名加载全景 |

## 目录结构

```
.
├── 4399/          # 4399 风格的小游戏平台（入口）
├── FlappyBird/    # Flappy Bird 游戏
└── RacingCar/     # 3D 城市赛车游戏
```

## 如何运行

因为游戏使用了 ES Modules 和 `fetch`，**不能直接双击 `index.html`** 用 `file://` 打开，需要通过本地服务器访问。

请在**项目根目录**（即包含 `4399`、`FlappyBird`、`RacingCar` 三个文件夹的目录）下启动服务器：

```bash
python -m http.server 8200
```

然后浏览器打开（**注意地址末尾的 `/` 不能少**）：

```
http://localhost:8200/4399/
```

> 注意：服务器根目录必须设在项目根目录，而不是 `4399/` 文件夹内，否则平台无法加载到两个游戏。

## 玩法

- 进入平台首页后，点击任意游戏卡片即可开始游玩
- **Flappy Bird**：空格（玩家1）/ W（玩家2）控制小鸟
- **城市狂飙 3D**：← / →（或 A / D）切换车道躲避车辆，输入城市名可加载对应全景（无网络时自动使用程序化城市天际线）

## 技术栈

- 原生 HTML / CSS / JavaScript（ES6+）
- [Three.js](https://threejs.org/)（3D 赛车渲染）
- Canvas 2D（Flappy Bird）
- 全程由大模型辅助生成
